# Fundacja Wielkie Serca

Strona one page fikcyjnej fundacji wspierającej dzieci chore na nowotwory.
Praca zaliczeniowa z informatyki: Dawid Fila, Patryk Fac, Stanisław Korulczyk,
V LO im. Marii Skłodowskiej-Curie w Lublinie, 2026.

## Pliki

- `index.html` - treść strony
- `css/style.css` - wygląd (kolory w zmiennych na początku pliku)
- `js/script.js` - funkcje: kopiowanie KRS, kalkulator 1,5%, odliczanie do 30 kwietnia,
  liczniki, pasek celu, tryb ciemny, powiększanie tekstu, wysoki kontrast, animacje
- `img/` - zdjęcia z licencją CC0 (StockSnap.io, Flickr)

## Jak obejrzeć

Otwórz `index.html` w przeglądarce (dwuklik).

## Publikacja na GitHub Pages

1. Załóż konto na github.com i nowe publiczne repozytorium, np. `wielkie-serca`.
2. W repozytorium kliknij Add file > Upload files i przeciągnij całą zawartość tego folderu
   (index.html, README.md oraz foldery css, js, img). Kliknij Commit changes.
3. Wejdź w Settings > Pages. W Source wybierz Deploy from a branch, gałąź `main`, folder `/ (root)`, Save.
4. Po 1-2 minutach strona będzie pod adresem `https://NAZWA-UZYTKOWNIKA.github.io/wielkie-serca/`.
